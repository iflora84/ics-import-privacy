iPhone won't add an .ics file to Calendar: every fix

You got a class timetable, a match schedule or a meeting invite as an .ics file. The iPhone shows it, but there's no way to put it in Calendar. Here's why, and what works.

Why it happens

iOS only offers "Add to Calendar" when the file is opened by an app that knows how to hand it to Calendar, mainly Apple Mail and Safari. Most other apps just pass the file to the share sheet, and the share sheet has no Calendar option:

  • Gmail, Outlook, Spark: attachments open in a preview or the share sheet
  • WhatsApp, Telegram, Messages: the file is treated as a generic document
  • Files app: shows a text preview of the file, with no Add button

Even when iOS can open the file, some files fail: times hours off (Outlook/Exchange time zone names), or updated invites that don't replace the old event.

Fix 1: open it in Apple Mail

If the file came by email, forward it to an address you read in Apple's Mail app, then tap the attachment there. Mail shows the event with an Add To Calendar button. This works well for a single invite.

Fix 2: open the link in Safari

If the .ics file is a download link on a website (course portals, sports clubs, ticket sites), long-press the link and open it in Safari rather than in an in-app browser. Safari offers to add the events.

Fix 3: subscribe instead of importing

If you were given a URL (often starting with webcal:// or ending in .ics) rather than a file, subscribe to it so it keeps updating: Settings › Calendar › Accounts › Add Account › Other › Add Subscribed Calendar. On iOS 18 and later, Calendar is under Settings › Apps.

Fix 4: import on a computer

  • Mac: open the file in Calendar, or use File › Import, and pick an iCloud calendar. It syncs to your iPhone.
  • Windows or any browser: in Google Calendar on the web, open Settings › Import & export and import the file. If your Google account is added to the iPhone (Settings › Calendar › Accounts), the events show up there.
